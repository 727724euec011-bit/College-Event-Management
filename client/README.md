# College Event Management System

A full-stack MERN web application for managing college events.

## Features

### Student
- Register and login
- View college events
- Search events
- Register for events
- View registered events

### Admin
- Admin login
- Create events
- Edit events
- Delete events
- View registered students

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- Axios
- React Router
- CSS
- Postman
